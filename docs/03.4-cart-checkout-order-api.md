# 03.4. Cart, Checkout & Order API Reference

Velora coordinates the shopping cart lifecycle, Stripe payment intent creation, and order placement across several unified endpoints.

---

## 1. Cart API Endpoints

Base Path: `/api/server/cart`

### 1.1. Get User Cart
- **Method**: `GET`
- **Path**: `/api/server/cart`
- **Auth Guard**: `requireCustomer` (Bearer Token)
- **Response**: `200 OK` (Returns active `Cart` document with items, subtotal, and tax).

### 1.2. Add Item to Cart
- **Method**: `POST`
- **Path**: `/api/server/cart`
- **Auth Guard**: `requireCustomer`
- **Request Body**:
  ```json
  {
    "productId": "664b3c90a12e8b2f90a4d5f1",
    "name": "Classic Minimalist Watch",
    "newPrice": 119.99,
    "quantity": 1,
    "selectedColor": "Black",
    "selectedSize": "One Size",
    "image": "https://example.com/watch.jpg"
  }
  ```
- **Response**: `201 Created`

### 1.3. Update Cart Item Quantity
- **Method**: `PATCH`
- **Path**: `/api/server/cart`
- **Auth Guard**: `requireCustomer`
- **Request Body**:
  ```json
  {
    "itemId": "664b3ca0a12e8b2f90a4d5f5",
    "quantity": 3
  }
  ```
- **Response**: `200 OK`

### 1.4. Remove Item / Clear Cart
- **Remove Item**: `DELETE /api/server/cart` with `{ "itemId": "..." }` -> `200 OK`
- **Clear Cart**: `DELETE /api/server/cart/clear` -> `200 OK`

## 2. Checkout & Order API Endpoints

Base Path: `/api/server/checkout`

### 2.1. Create Order & Stripe PaymentIntent
- **Method**: `POST`
- **Path**: `/api/server/checkout`
- **Auth Guard**: `requireCustomer`
- **Request Body**:
  ```json
  {
    "currency": "USD",
    "items": [
      {
        "productId": "664b3c90a12e8b2f90a4d5f1",
        "name": "Classic Minimalist Watch",
        "quantity": 1,
        "newPrice": 119.99,
        "selectedColor": "Black",
        "selectedSize": "One Size"
      }
    ],
    "addressSnapshot": {
      "street": "742 Evergreen Terrace",
      "city": "Springfield",
      "country": "United States",
      "postalCode": "97477"
    }
  }
  ```
- **Response**: `201 Created`
  ```json
  {
    "_id": "664b3cb0a12e8b2f90a4d601",
    "data": {
      "_id": "664b3cb0a12e8b2f90a4d601",
      "subtotal": 119.99,
      "shipping": 0,
      "tax": 0,
      "total": 119.99,
      "currency": "USD",
      "paymentStatus": "pending",
      "orderStatus": "pending"
    },
    "paymentIntent": {
      "paymentIntentId": "pi_3P...",
      "clientSecret": "pi_3P..._secret_...",
      "amount": 119.99,
      "currency": "USD"
    }
  }
  ```

### 2.2. List Customer Orders
- **Method**: `GET`
- **Path**: `/api/server/checkout/order` (or `/api/server/checkout`)
- **Auth Guard**: `requireCustomer`
- **Response**: `200 OK` (Returns an array of orders placed by the customer).

### 2.3. Update Order Status (Admin / System)
- **Method**: `PATCH`
- **Path**: `/api/server/checkout/:id`
- **Request Body**: `{ "orderStatus": "processing" }`
- **Response**: `200 OK`
