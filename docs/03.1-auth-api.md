# 03.1. Authentication API Reference

Velora provides separate authentication endpoints for **Customers** and **Store Owners (Sellers)**.

---

## 1. Customer Authentication Endpoints

Base Path: `/api/server/customer`

### 1.1. Register Customer
- **Method**: `POST`
- **Path**: `/api/server/customer`
- **Rate Limit**: `authLimiter`
- **Request Body**:
  ```json
  {
    "fullName": "Test Customer",
    "email": "customer@example.com",
    "password": "password123"
  }
  ```
- **Response**: `201 Created`
  ```json
  {
    "source": "database",
    "existed": false,
    "data": {
      "_id": "664b3c10a12e8b2f90a4d5e1",
      "fullName": "Test Customer",
      "email": "customer@example.com",
      "isEmailVerified": false
    },
    "emailSent": true,
    "emailVerificationToken": "63f8..."
  }
  ```

### 1.2. Customer Login
- **Method**: `POST`
- **Path**: `/api/server/customer/login`
- **Rate Limit**: `authLimiter`
- **Request Body**:
  ```json
  {
    "email": "customer@example.com",
    "password": "password123"
  }
  ```
- **Response**: `200 OK`
  ```json
  {
    "message": "Login successful",
    "token": "eyJhbGciOi...",
    "refreshToken": "eyJhbGciOi...",
    "data": {
      "_id": "664b3c10a12e8b2f90a4d5e1",
      "fullName": "Test Customer",
      "email": "customer@example.com"
    }
  }
  ```

### 1.3. Refresh Customer Access Token
- **Method**: `POST`
- **Path**: `/api/server/customer/token/refresh`
- **Request Body**:
  ```json
  {
    "refreshToken": "eyJhbGciOi..."
  }
  ```
- **Response**: `200 OK`
  ```json
  {
    "token": "eyJhbGciOi..."
  }
  ```

### 1.4. Email Verification & Password Reset
- `POST /api/server/customer/email/verify` -> Request verification email.
- `POST /api/server/customer/email/verify/confirm` -> Confirm with token `{ "token": "..." }`.
- `POST /api/server/customer/password-reset` -> Request password reset email `{ "email": "..." }`.
- `POST /api/server/customer/password-reset/confirm` -> Reset password `{ "token": "...", "newPassword": "..." }`.

## 2. Store Owner (Seller) Authentication Endpoints

Base Path: `/api/server/store-owner`

### 2.1. Register Store Owner
- **Method**: `POST`
- **Path**: `/api/server/store-owner`
- **Request Body**:
  ```json
  {
    "storeOwnerName": "Seller User",
    "storeOwnerEmailAddress": "seller@example.com",
    "storeOwnerPassword": "Password123!"
  }
  ```
- **Response**: `201 Created`

### 2.2. Store Owner Login
- **Method**: `POST`
- **Path**: `/api/server/store-owner/login`
- **Request Body**:
  ```json
  {
    "storeOwnerEmailAddress": "seller@example.com",
    "storeOwnerPassword": "Password123!"
  }
  ```
- **Response**: `200 OK` (Returns JWT access token with `"role": "seller"`).

### 2.3. Refresh Store Owner Token
- **Method**: `POST`
- **Path**: `/api/server/store-owner/token/refresh`
- **Request Body**: `{ "refreshToken": "..." }`
- **Response**: `200 OK` (`{ "token": "..." }`)
