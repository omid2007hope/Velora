# 02.2. BaseService & Repository Layer

The [`BaseService`](file:///h:/Omid/Code/Velora/Backend/services/BaseService/index.js) class serves as a centralized generic repository layer for MongoDB interactions across all 12 domain services in Velora.

---

## 1. Design & Objectives

Instead of writing repetitive Mongoose queries in every service, domain services inherit from `BaseService` by passing their respective Mongoose model:

```javascript
const BaseService = require("./BaseService");
const Product = require("../model/Product");

class ProductService extends BaseService {
  constructor() {
    super(Product);
  }
  // Domain-specific business logic methods...
}

module.exports = new ProductService();
```

---

## 2. Core Features of BaseService

### 2.1. Automatic Active Record Filtering (`_active`)
By default, all queries automatically exclude soft-deleted documents by merging `{ isDeleted: { $ne: true } }` into query filters:
```javascript
_active = (filter = {}) => ({ ...filter, isDeleted: { $ne: true } });
```

### 2.2. Pagination Engine (`findAllWithPagination`)
Provides standard pagination envelopes with computed metadata:
```javascript
findAllWithPagination = async (filter, { page = 1, limit = 10, sort }) => {
  const currentPage = Math.max(1, Number(page) || 1);
  const pageSize = Math.max(1, Number(limit) || 10);
  const activeFilter = this._active(filter);
  const [data, total] = await Promise.all([
    this.model
      .find(activeFilter)
      .sort(sort)
      .skip((currentPage - 1) * pageSize)
      .limit(pageSize),
    this.model.countDocuments(filter),
  ]);
  const pages = Math.ceil(total / pageSize);

  return {
    data,
    metaData: { pages, total, currentPage },
  };
};
```

### 2.3. Hierarchical Tree Construction (`_buildTree` & `findAllRecursive`)
Recursively loads nested entities (such as hierarchical product categories or reply chains):
```javascript
_buildTree = async (nodes, parentField) =>
  Promise.all(
    nodes.map(async (node) => {
      const children = await this.model.find(this._active({ [parentField]: node._id }));
      return {
        ...node.toObject(),
        child: children.length ? await this._buildTree(children, parentField) : [],
      };
    })
  );
```

### 2.4. Soft Deletion & Recovery
Documents are flagged with deletion metadata rather than removed from the physical disk:
```javascript
softDelete = async (filter, user) =>
  this.model.findOneAndUpdate(
    filter,
    { isDeleted: true, deletedBy: user, deletedAt: new Date() },
    { returnDocument: "after" }
  );

restoreSoftDelete = async (filter) =>
  this.model.findOneAndUpdate(
    filter,
    { isDeleted: false, deletedBy: "" },
    { returnDocument: "after" }
  );
```

## 3. BaseService Method Reference

| Method Signature | Return Value | Description |
|---|---|---|
| `createObject(documentData)` | `Promise<Document>` | Instantiates and saves a new document |
| `findById(id)` | `Promise<Document \| null>` | Finds active document by `_id` |
| `findByIdPopulate(id, populate)` | `Promise<Document \| null>` | Finds active document by `_id` with populated refs |
| `findOneByCondition(filter)` | `Promise<Document \| null>` | Finds first matching active document |
| `findOneByConditionAndPopulate(filter, pop)` | `Promise<Document \| null>` | Finds first matching active document with populated refs |
| `findAll(filter)` | `Promise<Document[]>` | Returns all active documents matching filter |
| `findAllByThisId(id, field)` | `Promise<Document[]>` | Returns active documents where `[field] === id` |
| `findAllWithSort(filter, sort)` | `Promise<Document[]>` | Returns sorted active documents |
| `findAllWithPagination(filter, opts)` | `Promise<{ data, metaData }>` | Returns paginated items and page metadata |
| `findAllAndPopulate(filter, populate)` | `Promise<Document[]>` | Returns active documents with populated references |
| `findAllRecursive(parentField)` | `Promise<TreeDocument[]>` | Reconstructs hierarchical tree from root nodes |
| `findAllDeleted()` | `Promise<Document[]>` | Returns soft-deleted documents (`isDeleted: true`) |
| `update(filter, updateData, returnNew)` | `Promise<Document \| null>` | Updates matching document |
| `updateAll(filter, updateData)` | `Promise<UpdateResult>` | Updates all matching documents |
| `softDelete(filter, user)` | `Promise<Document \| null>` | Sets `isDeleted: true`, `deletedBy`, `deletedAt` |
| `softDeleteRecursive(parentField, filter, user)` | `Promise<TreeDocument[]>` | Soft-deletes a parent and all its descendant children |
| `restoreSoftDelete(filter)` | `Promise<Document \| null>` | Clears `isDeleted` flag and restores document |
| `hardDelete(filter)` | `Promise<Document \| null>` | Permanently deletes a single document |
| `hardDeleteMany(filter)` | `Promise<DeleteResult>` | Permanently deletes all matching documents |
