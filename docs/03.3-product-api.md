# 03.3. Product Management & Catalog API Reference

The Product API supports public catalog discovery (search, category filtering, product details) and merchant-scoped product management (creation, updates, stock management, deletion).

---

## 1. Public Catalog Endpoints

### 1.1. List & Filter Products
- **Method**: `GET`
- **Path**: `/api/server/product`
- **Auth**: None (Public)
- **Query Parameters**:
  - `category` *(optional string)*: Filter by top-level category (e.g. `Men`, `Women`, `Electronics`).
  - `subCategory` *(optional string)*: Filter by sub-category (e.g. `T-Shirts`, `Shoes`).
  - `search` *(optional string)*: Search text across name and description.
  - `new` *(optional boolean: `true` / `false`)*: Filter for new arrivals (`NewArrivals: true`).
  - `storeId` *(optional ObjectId)*: Filter by specific merchant store.
- **Response**: `200 OK`
  ```json
  {
    "data": [
      {
        "_id": "664b3c90a12e8b2f90a4d5f1",
        "storeId": "664b3c80a12e8b2f90a4d5e5",
        "name": "Classic Minimalist Watch",
        "description": "Premium stainless steel timepiece.",
        "oldPrice": 149.99,
        "newPrice": 119.99,
        "category": "Accessories",
        "subCategory": "Watches",
        "imageUrl": "https://example.com/images/watch.jpg",
        "color": ["Silver", "Black"],
        "size": ["One Size"],
        "NewArrivals": true
      }
    ]
  }
  ```

### 1.2. Get Product by ID
- **Method**: `GET`
- **Path**: `/api/server/product/:id`
- **Auth**: None
- **Response**: `200 OK`

## 2. Merchant Product Management Endpoints

### 2.1. Create Product
- **Method**: `POST`
- **Path**: `/api/server/store/products`
- **Auth Guard**: `requireSeller` (Bearer Token)
- **Validation**: `validateCreateProduct`
- **Request Body**:
  ```json
  {
    "storeId": "664b3c80a12e8b2f90a4d5e5",
    "name": "Organic Cotton Tee",
    "description": "100% certified organic heavyweight cotton tee.",
    "oldPrice": 45.00,
    "newPrice": 35.00,
    "discount": "22% OFF",
    "category": "Clothing",
    "subCategory": "T-Shirts",
    "imageUrl": "https://example.com/tee.jpg",
    "color": ["White", "Sage", "Navy"],
    "size": ["S", "M", "L", "XL"],
    "NewArrivals": true,
    "highlights": ["100% Organic Cotton", "Pre-shrunk fabric", "Made ethically"]
  }
  ```
- **Response**: `201 Created`

### 2.2. List Products by Store ID
- **Method**: `GET`
- **Path**: `/api/server/store/products/:id`
- **Auth**: None / Seller
- **Response**: `200 OK` (Returns all active products belonging to the store).

### 2.3. Update Product
- **Method**: `PATCH`
- **Path**: `/api/server/store/products/:id`
- **Auth Guard**: `requireSeller`
- **Request Body**: Partial update object (e.g. `{ "newPrice": 29.99 }`)
- **Response**: `200 OK`

### 2.4. Soft Delete Product
- **Method**: `DELETE`
- **Path**: `/api/server/store/products/:id`
- **Auth Guard**: `requireSeller`
- **Response**: `200 OK` (Sets `isDeleted: true` and `deletedBy: req.user.id`).
