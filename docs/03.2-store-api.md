# 03.2. Store Management API Reference

The Store API enables merchants to register, update, retrieve, and manage their storefront profiles.

---

## 1. Store Endpoints Reference

### 1.1. Create Store
- **Method**: `POST`
- **Path**: `/api/server/seller/store`
- **Auth Guard**: `requireSeller` (Bearer Token)
- **Validation**: `validateCreateStore`
- **Request Body**:
  ```json
  {
    "storeName": "Velora Boutique",
    "storeDescription": "Curated lifestyle and fashion essentials",
    "countryStoreLocatedIn": "United States",
    "stateOrProvinceStoreLocatedIn": "California",
    "cityStoreLocatedIn": "Los Angeles",
    "storeAddress": "123 Market Street",
    "storeZipcode": "90001"
  }
  ```
- **Response**: `201 Created`
  ```json
  {
    "data": {
      "_id": "664b3c80a12e8b2f90a4d5e5",
      "ownerOfStore": "664b3c10a12e8b2f90a4d5e1",
      "storeName": "Velora Boutique",
      "storeDescription": "Curated lifestyle and fashion essentials",
      "countryStoreLocatedIn": "United States",
      "stateOrProvinceStoreLocatedIn": "California",
      "cityStoreLocatedIn": "Los Angeles",
      "storeAddress": "123 Market Street",
      "storeZipcode": "90001",
      "createdAt": "2026-05-20T10:00:00.000Z",
      "updatedAt": "2026-05-20T10:00:00.000Z"
    }
  }
  ```

### 1.2. Get Store by Owner ID
- **Method**: `GET`
- **Path**: `/api/server/seller/auth/store/:id`
- **Auth Guard**: `requireSeller`
- **Response**: `200 OK` (Returns the store matching the authenticated owner).

### 1.3. Get Store by ID
- **Method**: `GET`
- **Path**: `/api/server/store/:id`
- **Auth Guard**: None (Public storefront view)
- **Response**: `200 OK`

### 1.4. Update Store Information
- **Method**: `PATCH`
- **Path**: `/api/server/seller/store/:id`
- **Auth Guard**: `requireSeller`
- **Request Body**: Partial update object (e.g., `{ "storeName": "Velora Studio" }`)
- **Response**: `200 OK`

### 1.5. Soft Delete Store
- **Method**: `DELETE`
- **Path**: `/api/server/seller/store/:id`
- **Auth Guard**: `requireSeller`
- **Response**: `200 OK` (Marks `isDeleted: true` and cascade-deletes related store products).
