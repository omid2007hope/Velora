# 01.1. Getting Started & Development Setup

This guide provides step-by-step instructions for setting up the Velora development environment locally.

---

## 1. Prerequisites

Ensure your development machine meets the following version requirements:

- **Node.js**: `v20.11.1` or higher (`<21`)
- **npm**: `v10.x` or higher
- **MongoDB**: Local MongoDB instance (`mongodb://localhost:27017`) or a MongoDB Atlas connection URI
- **Stripe Account**: A test-mode Stripe account for testing payments and webhooks

---

## 2. Repository Cloning & Environment Setup

Clone the repository to your local workstation:

```bash
git clone https://github.com/omid2007hope/Velora.git
cd Velora
```

---

## 3. Backend Setup

### 3.1. Install Dependencies
Navigate into the `Backend/` directory and install the required npm packages:

```bash
cd Backend
npm install
```

### 3.2. Configure Environment Variables
Create a `.env` file in the `Backend/` root:

```ini
# Server Configuration
PORT=4000
NODE_ENV=development
ALLOWED_ORIGINS=http://localhost:3000

# Database
MONGO_URI=mongodb://127.0.0.1:27017/velora

# Authentication / JWT
JWT_SECRET=your_super_secret_jwt_key_32_characters_minimum
JWT_EXPIRES_IN=1d
REFRESH_TOKEN_SECRET=your_super_secret_refresh_token_key_minimum
REFRESH_TOKEN_EXPIRES_IN=7d

# Stripe Integration
STRIPE_SECRET_KEY=sk_test_51...
STRIPE_WEBHOOK_SECRET=whsec_...

# Email Transport (Nodemailer / EmailJS)
EMAIL_SERVICE=smtp
EMAIL_USER=your_email@example.com
EMAIL_PASS=your_email_password
EMAIL_FROM="Velora <no-reply@velora.com>"
```

### 3.3. Run the Backend
Start the development server with automatic file reloading via Nodemon:

```bash
npm run dev
```

The REST API will boot and listen on `http://localhost:4000`. You can verify server health at:
- `GET http://localhost:4000/health` (Returns `{"status": "ok"}`)
- `GET http://localhost:4000/api/server` (Returns `"server is running"`)

---

## 4. Frontend Setup

### 4.1. Install Dependencies
Open a new terminal window, navigate to `Frontend/`, and install dependencies:

```bash
cd Frontend
npm install
```

### 4.2. Configure Environment Variables
Create a `.env.local` file in the `Frontend/` root:

```ini
# Backend API Base URL
NEXT_PUBLIC_API_URL=http://localhost:4000/api

# Public Stripe Key for Elements
NEXT_PUBLIC_STRIPE_PUBLISHABLE_KEY=pk_test_51...
```

### 4.3. Run the Frontend
Start the Next.js development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the Velora storefront.

---

## 5. Running the Automated Test Suite

The backend includes a comprehensive Jest integration test suite configured to use an in-memory MongoDB server (`mongodb-memory-server`), requiring no live database connection.

To execute tests:

```bash
cd Backend
npm test
```

For continuous testing during development:

```bash
npm run test:watch
```

## 6. Available Scripts Summary

| Directory | Command | Description |
|---|---|---|
| `Backend/` | `npm run dev` | Starts the Express server with Nodemon on port 4000 |
| `Backend/` | `npm start` | Runs the production Express server |
| `Backend/` | `npm test` | Runs Jest integration test suite in-band |
| `Frontend/` | `npm run dev` | Starts Next.js development server on port 3000 |
| `Frontend/` | `npm run build` | Builds the Next.js production bundle |
| `Frontend/` | `npm run lint` | Checks code formatting and ESLint rules |
