# 02.6. Utilities & Shared Infrastructure

Velora provides a focused suite of shared helper modules located in [`Backend/utils/`](file:///h:/Omid/Code/Velora/Backend/utils/) supporting error normalization, logging, async route wrapping, Stripe client configuration, and email notifications.

---

## 1. Utilities Inventory

### 1.1. HTTP Error Factory (`httpError.js`)
Normalizes operational errors across controllers and services into consistent Error instances carrying HTTP status codes and structured validation metadata:
```javascript
function createHttpError(status, message, details) {
  const error = new Error(message);
  error.status = status;

  if (details !== undefined) {
    error.details = details;
  }

  return error;
}

module.exports = { createHttpError };
```

### 1.2. Async Handler Wrapper (`asyncHandler.js`)
Eliminates repetitive `try / catch` blocks in Express controller handlers by wrapping asynchronous functions and routing rejected promises to `next(err)`:
```javascript
const asyncHandler = (fn) => (req, res, next) => {
  Promise.resolve(fn(req, res, next)).catch(next);
};

module.exports = asyncHandler;
```

### 1.3. Centralized Logger (`logger.js`)
Provides structured, leveled logging for server bootstrap, database connection state, incoming requests, and fatal errors:
- `logger.info(message)`
- `logger.error(message, error)`
- `logger.warn(message)`

### 1.4. Stripe SDK Client & Test Mocks (`stripeClient.js`)
Configures the official Stripe Node.js SDK when `STRIPE_SECRET_KEY` is present. In local development or testing environments without active credentials, it falls back seamlessly to a realistic in-memory mock client generating synthetic `pi_mock_...` client secrets.

### 1.5. Email Dispatcher (`mailer.js`)
Integrates email transport mechanisms (Nodemailer and EmailJS) to dispatch:
- **Email Verification Codes**: Sent during customer and store-owner onboarding.
- **Password Reset Links**: Secure tokens sent when users initiate password recovery.
- **Order Confirmations**: Receipt emails triggered following successful checkout.
